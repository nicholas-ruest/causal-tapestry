# Causal Tapestry

Design status: architecture frozen; implementation not yet started.

Causal Tapestry reconstructs multi-service incidents, ranks root-cause hypotheses with anytime-valid causal evidence, recalls analogous investigations through RuVector, gates remediation proposals with Microsoft Regorus, and seals replayable RVF evidence bundles.

See [specification](docs/specification.md), [architecture](docs/architecture.md), [research](docs/research.md), [ADRs](docs/adrs/README.md), and [DDD model](docs/ddd/README.md).
